# Local client source

`lib/client.js` is generated by concatenating the numbered `*.part.js` files in
this directory. The parts share the lexical scope of DSH's ModuleLoader factory;
they are split by ownership so bridge/store, workspace UI, overlay/settings, and
registration changes no longer require editing one 200 KB release artifact.

`10-official-workspace.part.js` is generated from the pinned upstream
`ui-workspace` fork. Keep its baseline and delta record under
`packages/local/upstream/ui-workspace/` in sync when rebasing.

Run `npm run build` after editing a part. `npm run check` rejects stale generated
clients.
